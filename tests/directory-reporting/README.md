# Original directory-reporting profiles

Forty independently authored models cover explicit and automatic directory
reporting, silent and inherited/live flag policy, startup metadata phases,
failed directory changes, remakes, output-sync groups and two native finalizers.
The 38 ordinary cases never compile C. Only the two declared finalizer profiles
compile the original module, once before both GNU executions and the candidate.
No GNU implementation, header or tests are copied or translated.

The runner expands static `@WORK@`, `@HOME@` and `@TMP@` byte tokens solely from
the predetermined reset workspace before execution. It checks complete streams,
status, ordered `seen`, full filesystem state, GNU repeat equality and process
bounds. Filesystem expectations come from prepared inputs plus declared updates,
independently of child observations. Extra or missing groups/files, shared wrong
paths/state, leftovers and resource limits always fail.

One version case has a fixed `@VERSION@` slot. Each engine's isolated version
banner must be stable, leave the fixture unchanged and contain no directory
boundary. The entire case stream must then match its template exactly. This
permits branding differences while preserving every directory path, boundary,
position and count. No output-derived path or diagnostic normalization is used.

Run `make test-directory-reporting`, optionally with
`DIRECTORY_REPORT_CASE=directory-explicit-w`. The standalone tool accepts
`--oracle`, `--candidate` or `--oracle-only`, `--report`, repeated exact `--case`
IDs and optional `--cc` for the two native cases. GNU-only qualification receives
no candidate credit; these separate profiles add no ordinary-ledger or approved
safety-exception credit. The existing 215-model native gate remains unchanged.

[history.json](history.json) checksums all complete original first/parallel/final
models, observers, raw observations, verifier and handoff, plus transformed GNU2
and preceding-candidate reports and integration-source snapshots. All 40 GNU2
models pass; the frozen preceding candidate passes four and fails 36. Initial
incorrect warning/spool predictions and the qualified serial/parallel choices
remain recorded without expanding the selected inventory. Compiled libraries
are excluded from the archive while their hashes remain retained.
