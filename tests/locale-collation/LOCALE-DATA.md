`tools/locale_data.py` provisions a private `fr_FR.UTF-8` locale for the selected Linux/x86-64 glibc 2.39 comparison profile. It requires no installed French locale. `provision(destination)` returns `environment.LOCPATH` as an absolute path and records the locale name, signed package provenance, every generated file hash and input/license identities in `destination/profile.json`.

The lock is `oracle/locale-data.json`. It authenticates Ubuntu noble's pinned `InRelease` with the exact Ubuntu Archive signing fingerprint, verifies the main package index against signed SHA-256 metadata, and checks the exact `locales` and `libc-bin` 2.39-0ubuntu8 archives. It extracts those archives locally with `dpkg-deb -x`; package installation and maintainer scripts are never invoked. The packaged `localedef` reads the pinned locale data and independently decompressed UTF-8 charmap through a private `I18NPATH`. Its output is accepted only at the full locked file/mode/content/hardlink tree hash. It does not modify `/usr`, the system locale archive or global locale settings.

Run `python3 -B tools/locale_data.py --root DESTINATION`. The CLI prints the profile JSON. Every invocation reauthenticates source metadata and verifies cached input and output trees before checking that host libc can load the locale. Cache metadata is atomically replaced, existing symlinks are rejected, and the generator receives an explicit `022` umask for reproducible modes. Generated output hash: `6bbef6b878271d58f9e4451f9cfb89d22358f006eb829ef2721e83c8f07a68c5`.

Eight tooling tests cover pinned identities, changed download bytes/sizes, insecure redirects, cache symlinks, signature/index/package substitutions, unsafe metadata paths, changed input/output trees, special files, private generator arguments and fail-closed platform/unpinned-lock behavior. A fresh cold download/extraction/generation and a verified warm reuse both passed. `locale-data-history.json.gz` retains the original bootstrap, first and final helper sources, complete cold/warm profiles, raw signature/package metadata, inventories, commands and check logs with embedded SHA-256 records. Third-party package/data bytes remain in the external cache; their authenticated identities and licenses are pinned by the repository lock.

This provisioner supplies test data, not GNU Make compatibility credit. Its host boundary is Linux/x86-64 glibc 2.39. Other distributions, libc versions, architectures and locales remain separate profiles.
